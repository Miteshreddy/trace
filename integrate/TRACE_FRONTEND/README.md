# TRACE — Premium Frontend v4

A standalone, premium SaaS frontend for TRACE, built around one product story:

**goal → live browser journey → evidence**

## What changed in v4

- Homepage redesigned from the supplied portfolio reference, without copying it.
- Header: TRACE logo left, Command / Live Screen / Evaluation in the center, dynamic run status right.
- Main hero: strong TRACE positioning, a glass intent tag, the exact existing prompt-typing animation, and the existing live console animation as the hero visual.
- No company logos, fake customer logos, ecommerce examples or branded target products.
- Evidence section inspired by the supplied lower-page reference with subtle scroll motion.
- Additional animated journey visualization using a traced path and cursor.
- Footer structure inspired by the supplied reference.
- Custom TRACE mark cursor and custom text-selection highlight.
- Existing Command and Live Session flows remain functional, including local storage/session storage and optional backend API configuration.

## Run

Double-click `setup_and_run.bat`, or serve this folder with any static server.

The homepage is `index.html`.
